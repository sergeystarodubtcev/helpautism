# Искра надежды — helpautism.ru

Восстановленная копия сайта ВРООИ «Искра надежды». Старый сайт на WordPress (хостинг Beget) взломали и удалили, эта копия собрана **1 в 1 из веб-архива (web.archive.org)**:
- дизайн — оригинальная тема WordPress Zerif Lite, как на сайте в октябре 2020 года;
- шрифты, картинки, документы, тексты всех записей — из архивных снимков;
- адреса страниц те же, что были (`/2020/10/05/voskresnaya-vstrecha/`), поэтому старые ссылки из соцсетей и поисковиков работают.

Сверху добавлен лёгкий слой анимаций (`assets/enhance.css`, `assets/enhance.js`): плавное появление блоков при прокрутке, наведение на новости и логотипы партнёров, кнопка «наверх». Цвета и вёрстку оригинала он не меняет.

Сайт **статический**: без PHP, базы данных и админки. Его нечем взломать, и он размещается где угодно.

## Что где

```
archive/2020/        — снимок сайта на 20.10.2020 (страницы, тема, плагины, картинки)
archive/latest/      — последние нормальные версии страниц (записи 2021–2022)
archive/cdx.json     — список всех снимков сайта в веб-архиве
assets/enhance.*     — анимации поверх оригинального дизайна
assets/fonts/        — шрифты (Montserrat, Open Sans, Oswald, Roboto), локально
assets/vendor/       — jQuery 3.1.0, локально
tools/build_site.py  — сборка сайта из архива в папку site/
tools/wayback_mirror.py, tools/fetch_requisites.py — скачивание из веб-архива
tools/fetch_fonts.py — скачивание шрифтов
.github/workflows/   — публикация на GitHub Pages и задачи скачивания архива
```

Сборка локально:

```bash
python3 tools/build_site.py
```

```bash
cd site && python3 -m http.server 8000
```

## Что не удалось восстановить

- **Записи с 2023 года.** С 2023 года веб-архив вместо страниц сохранял заглушку антибот-защиты Beget (`beget=begetok`), настоящего текста в архиве нет. Эти записи нужно добавить заново, если сохранились тексты.
- **Часть картинок.** Некоторые картинки (например, превью новостей октября 2020) архив не сохранил вообще. Если у уменьшенной копии есть оригинал, сборщик подставляет его.
- **Динамика WordPress:** формы обратной связи, календарь событий, поиск. Формы открывают письмо на helpautismvrn@gmail.com, поиск ведёт в Яндекс по сайту.

## Публикация

GitHub Pages: любой push в ветку собирает сайт (`tools/build_site.py`) и публикует папку `site/`.

Свой домен: файл `CNAME` с текстом `helpautism.ru` в корне репозитория, у регистратора — A-записи GitHub Pages (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`).

## Перенос на российские серверы (для гранта)

Готовый сайт — папка `site/` после сборки. Её можно загрузить:
- в Yandex Cloud Object Storage (статический хостинг бакета), Selectel или VK Cloud S3;
- на любой виртуальный хостинг (Beget, Timeweb, REG.RU) в `public_html`;
- на свой VPS с nginx.

Шрифты и jQuery уже лежат локально, сайт не обращается к серверам Google. Внешними остаются только виджеты ВКонтакте и ссылки на соцсети.
