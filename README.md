# Искра Надежды — helpautism.ru

Сайт ВРООИ «Искра Надежды». Статический: без PHP, базы данных и админки WordPress, поэтому взламывать на нём нечего, а разместить его можно где угодно (GitHub Pages сейчас, Яндекс Облако — далее).

## Откуда что берётся

| Что | Источник |
|---|---|
| Записи (642), страницы (55), меню, рубрики | экспорт WordPress → `content/` (JSON) |
| Картинки и документы | живой helpautism.ru (`wp-content/uploads`), сжатые → `media/` |
| Каркас и стили темы Zerif Lite, главная 2020 года | веб-архив → `archive/2020/` |
| Новое оформление (минимализм, мобильная версия, анимации) | `assets/modern.css`, `assets/enhance.js` |
| Формы | `content/forms.json` |

Адреса страниц такие же, как на старом сайте: `/2026/10/24/zaryadilis-energiej-i-znaniyami/`, `/kontakty/`, `/category/news/`.

## Сборка

```bash
python3 tools/build_site.py
```

```bash
cd site && python3 -m http.server 8000
```

GitHub Pages собирает и публикует сайт автоматически при каждом push.

## Обновить контент из нового экспорта WordPress

Экспорт («Инструменты → Экспорт → Все данные») **не класть в репозиторий**: в нём личные данные жертвователей. Положите файл рядом и выполните:

```bash
python3 tools/import_wxr.py /путь/к/WordPress.xml
```

Новые картинки: скачать адреса из `content/media.txt` с `https://helpautism.ru` во временную папку и сжать:

```bash
python3 tools/optimize_media.py /временная/папка media/
```

## Формы

Поля форм — в `content/forms.json`. Пока нет сервера, форма открывает письмо на helpautismvrn@yandex.ru с заполненными полями. После переезда в Яндекс Облако достаточно указать адрес обработчика (Cloud Functions) в `assets/config.js` → `FORMS_ENDPOINT`, и формы будут отправляться без почтовой программы.

Поля форм «Стать волонтёром», «Анкета в ресурсный класс» и «Простыми словами» не сохранились нигде — они составлены заново, проверьте.

## Не вошло

- 4 длинных видео (30–700 МБ) — слишком большие для GitHub, список в `media/skipped.txt`. Их стоит положить в Object Storage после переезда.
- 13 картинок, которых нет ни на сервере, ни в веб-архиве.
- Пожертвования онлайн (плагин Leyka) — на статическом сайте вместо формы оплаты показываются реквизиты.

## Перенос на российские серверы

Готовый сайт — папка `site/`. Подойдут Yandex Cloud Object Storage (хостинг статического сайта), Selectel, VK Cloud или любой хостинг. Шрифты и скрипты лежат локально, к Google сайт не обращается. Админку для новостей планируется сделать после переезда (контент уже в JSON).
