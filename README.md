# Искра надежды — helpautism.ru

Новый сайт ВРООИ «Искра надежды». Он заменяет старый сайт на WordPress, который взломали на хостинге Beget.

Сайт **полностью статический**: нет PHP, нет базы данных, нет сервера. Весь контент хранится в JSON-файлах в папке `data/`. Поэтому сайт:
- работает на GitHub Pages бесплатно;
- переносится на любой российский хостинг простым копированием файлов;
- почти не поддаётся взлому: на сервере нечего взламывать (нет админки, PHP и базы).

## Структура

```
index.html            — оболочка сайта
404.html              — перенаправляет старые адреса WordPress (/2021/01/15/slug/) на новые
assets/css/style.css  — дизайн и анимации
assets/js/app.js      — вывод страниц из JSON (роутинг #/news, #/projects, ...)
assets/uploads/       — картинки и документы, восстановленные из архива
data/site.json        — название, контакты, меню, блок пожертвований, цифры на главной
data/projects.json    — проекты и направления
data/news.json        — новости и статьи
data/pages.json       — прочие страницы старого сайта
tools/wayback_import.py — восстановление текстов и картинок из web.archive.org
```

## Как редактировать контент

Откройте нужный JSON-файл на GitHub (кнопка ✏️), измените текст и сохраните (Commit). Через 1–2 минуты сайт обновится сам.

Добавить новость: скопируйте любой блок `{ ... }` в `data/news.json` и поменяйте `slug` (латиницей, без пробелов), `title`, `date` (ГГГГ-ММ-ДД), `excerpt` (кратко) и `content` (HTML). Поставьте `"restored": true`, чтобы скрыть плашку «текст переносится».

## Восстановление старых текстов из веб-архива

Из облачной среды, где собирался сайт, web.archive.org недоступен. Скрипт запускается на любом компьютере с Python 3:

```bash
git clone <этот репозиторий> && cd helpautism
python3 tools/wayback_import.py
git add data assets/uploads && git commit -m "Восстановлен контент из веб-архива" && git push
```

Скрипт найдёт все сохранённые в архиве страницы helpautism.ru, вытащит из них заголовки, даты, тексты и картинки и запишет их в `data/news.json`, `data/pages.json` и `assets/uploads/`. Можно запускать повторно: уже восстановленное он пропускает.

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages → Source: GitHub Actions**.
2. Любой push в `main` (или в рабочую ветку) запускает workflow `.github/workflows/pages.yml`, и сайт публикуется.
3. Свой домен: создайте в корне файл `CNAME` с текстом `helpautism.ru` и у регистратора домена пропишите DNS-записи GitHub Pages (A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`).

> GitHub Pages для **приватного** репозитория доступен только на платных тарифах GitHub (Pro/Team). На бесплатном тарифе репозиторий нужно сделать публичным. Можно оставить приватным только репозиторий с черновиками.

## Перенос на российские серверы (для гранта)

Сайт — это просто папка файлов, поэтому подойдёт любой российский хостинг:
- **Yandex Cloud Object Storage** (статический хостинг в бакете) или **Selectel / VK Cloud S3**;
- любой виртуальный хостинг (Beget, Timeweb, REG.RU): загрузить файлы в `public_html`;
- свой VPS с nginx.

Публикуемые файлы: `index.html`, `404.html`, `assets/`, `data/`. Чтобы старые ссылки работали, у сервера нужно указать `404.html` как страницу ошибки 404.

Перед переносом стоит отказаться от зарубежных сервисов. Сейчас подключены шрифты Google Fonts; для соответствия 152-ФЗ их лучше положить локально в `assets/fonts`. Карта уже на Яндекс Картах.
